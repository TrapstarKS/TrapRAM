A visual and UX polish pass across the workspace.

### Changed

- Disabled primary buttons are now neutral grey instead of faded violet, so Launch no longer looks clickable before accounts are selected.
- Each account shows a single status indicator: the avatar badge reflects presence, and session problems appear as amber status text.
- Removed the repeated "Roblox workspace" label and duplicate section titles for more vertical room on every tab.
- Performance hides Tray, Arrange and Close all until a Roblox client is running.
- Windows-only settings are hidden on macOS; the duplicate account-order control was removed from Settings (use Sort by in the sidebar).
- Shorter, clearer descriptions for client profile and multi-client settings.
- Private servers show the game name and explain why Join is unavailable without a signed-in account.
- Quick launch and Recently played cards are wider, show the game's initial when no icon is available, and label fixed-server favourites clearly.
- Games without artwork show their initial instead of a large empty placeholder.
- The lock screen shows the TrapRAM name; the pin icon is larger with a tooltip; Job ID uses the same font size as the Experience field.
